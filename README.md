# Frontend AI Capstone

An AI-assisted frontend engineering capstone project.

## Purpose

This project is being developed as part of the FlyRank Front-end AI Engineering internship.

## Planned Stack

- Next.js
- TypeScript
- Tailwind CSS

## Development Approach

This project will use AI-assisted development while maintaining clean, accessible, reusable, and maintainable code.

## Current Status

The minimal Next.js App Router baseline is set up with TypeScript, Tailwind CSS, and testing tools. The Settings Form has not been implemented yet.

## Getting Started

Install dependencies and start the Next.js development server from the project root.

### Prerequisites

- Git
- Node.js 20.9 or later

### Clone the repository

```bash
git clone https://github.com/khaled1267/frontend-ai-capstone.git
cd frontend-ai-capstone
```

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

Run the baseline checks with:

```bash
npm test
npm run lint
npm run typecheck
npm run build
```

## Project Goals

The goals of this capstone project are to:

- Build a modern frontend application using Next.js and TypeScript.
- Create responsive and accessible user interfaces.
- Follow clean, reusable, and maintainable coding practices.
- Use AI tools responsibly to support development and problem-solving.
