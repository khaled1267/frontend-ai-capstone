# Frontend AI Capstone

An AI-assisted frontend engineering capstone project.

## Purpose

This project is being developed as part of the FlyRank Front-end AI Engineering internship.

## Planned Stack

- Next.js
- TypeScript
- Tailwind CSS

## Development Approach

This project will use AI-assisted development while maintaining clean, accessible, reusable, and maintainable code.

## Current Status

Repository setup is complete. The capstone development will begin in the upcoming assignments.

## Project Goals

The goals of this capstone project are to:

- Build a modern frontend application using Next.js and TypeScript.
- Create responsive and accessible user interfaces.
- Follow clean, reusable, and maintainable coding practices.
- Use AI tools responsibly to support development and problem-solving.
