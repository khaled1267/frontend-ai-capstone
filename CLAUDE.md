# Project Guidelines

## Project Overview

This is a frontend AI engineering capstone project developed as part of the FlyRank internship.

## Stack

- Next.js
- TypeScript
- Tailwind CSS

## Coding Conventions

- Use TypeScript for all application code.
- Use functional React components.
- Keep components small and reusable.
- Follow a clean and maintainable folder structure.
- Use semantic HTML elements.
- Build accessible user interfaces.
- Keep the code simple and readable.
- Avoid unnecessary dependencies.
- Follow consistent naming conventions.

## AI-Assisted Development

- Use AI tools to assist with development and problem solving.
- Review AI-generated code before using it.
- Prefer simple, maintainable solutions.
- Do not blindly accept AI-generated code.
- Test important changes before committing them.
